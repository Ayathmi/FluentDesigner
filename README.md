## FluentDesigner

为独立游戏《星轨韵律》设计的关卡/谱面编辑器。编辑器与游戏本体均由Ayathmi创建。

关注 B站@小林绫子 获取最新动态。

需要安装dotNet 10，最低支持系统版本Win11 22H2。

------

## 核心特性

**大纲视图：** 基于WinUI 3的虚拟化渲染树状视图，支持批量选择与视图中改动；

**ECS：** 可自选音符组件，允许自定义音符速度动画，未来添加更多组件；

**并行化：** 支持并行导出与播放；

**实时预览：** 实现谱面实时倒带、时间跳转、循环片段等功能
